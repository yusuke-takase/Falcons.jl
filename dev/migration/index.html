Migrating from Falcons 1.0.1

This version follows litebird_sim's conventions and names, which changes both the API and some results:

  • ψ and the HWP angle follow litebird_sim (see Conventions); the detector polarisation angle is no longer added to the HWP angle.
  • h-maps use exp(+i(nψ + mχ)), the complex conjugate of the former exp(−i(nψ + mϕ)), and unobserved pixels are 0 instead of NaN. The (0, 0) couple holds the hit counts.
  • The focal-plane rotation is bore2spin = Rz(spin_rotangle) · Ry(β) · Rz(boresight_rotangle); the former gamma, start_point and name-dependent IMO rules are gone.
  • The Ecliptic-to-Galactic rotation uses litebird_sim's values (they differ from the former ones by up to 1e-7).
  • Hit maps, pixel indices and h-maps are in Galactic coordinates by default, as in litebirdsim; the former default was Ecliptic (coord = "E"). Pass `outputcoordinatesystem = Eclipticfor the former frame. Pointings (getpointings`) are still Ecliptic by default.
